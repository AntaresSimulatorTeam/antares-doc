# Debug tab

The debug tab allows the user to visualize all the input and output files
of an Antares study. A brief presentation of the file structure is available
[here](./file-structure.md).

You can directly import, export and edit files in this tab. 
However, it is not recommended to modify data here unless you know what you do. 

This tab is notably used to do some simple checks on the files 
and to export some output specific output files without a dedicated interface 
in Antares Web.
