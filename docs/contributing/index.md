# Contributing

Antares is open source! So we welcome any feedback and contribution from users and developpers.
All the source code is hosted on the [GitHub Antares organization](https://github.com/AntaresSimulatorTeam).

## Issues on GitHub

If you have find a bug, if you have new features ideas or if a documentation page is missing,
you can report an issue on GitHub on the relevant technical repository.
