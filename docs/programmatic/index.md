# Programmation and CLI

Sometimes, you will want to automate your workflow. For this, Antares has a python package 
[Antares Craft](https://github.com/AntaresSimulatorTeam/antares_craft) for interacting with 
Antares studies. You can essentially do what is possible in Antares Web and automate it
for many different studies, variant and adapt it to your workflow. 

You can also find some explanation on how to use the different executables in the command line:

- [antares-solver](antares-solver-cli.md)
- [antares-modeler](modeler-cli.md)
- [antares-xpansion](antares-xpansion-cli.md)
