# Code guidelines

Contributions to Antares are welcome! You can submit an issue on GitHub or a pull request. All the technical repositories are on GitHub within the [antares organization](https://github.com/AntaresSimulatorTeam). You can consult the `CONTRIBUTING.md` file for pieces of advice to start working on Antares. Here are links to the main repositories used in Antares:

- [Antares Simulator](https://github.com/AntaresSimulatorTeam/Antares_Simulator)
- [Antares Xpansion](https://github.com/AntaresSimulatorTeam/antares-xpansion)
- [Antares Web](https://github.com/AntaresSimulatorTeam/AntaREST)
- [Antares Craft](https://github.com/AntaresSimulatorTeam/antares_craft)

!!! tips

    Communication is key! Explain clearly the problems you encounter. Ask when you don't know how things work.
