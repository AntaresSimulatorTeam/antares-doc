# Tutorials

This section is aimed at responding to your "How to" questions that you might encounter 
when using Antares Web. 

If you want to automate things you might consider using 
[Antares Craft](https://github.com/AntaresSimulatorTeam/antares_craft)
which is Antares python package for interacting with studies on your machine or on the server.
A [brief presentation](../programmatic/antares-craft-overview.md) is available in the 
**Programmation and CLI** section.
